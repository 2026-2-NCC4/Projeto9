## Descrição

O DashBird é um projeto desenvolvido pelo grupo Los Meninos do Back, formado por estudantes de Ciência da Computação da FECAP, como parte do Projeto Interdisciplinar (PI).

<br><br>

A proposta consiste na criação de uma solução digital para apoiar a análise de dados e previsões financeiras, utilizando informações disponibilizadas no contexto da parceria acadêmica com a CTI.

<br><br>

A plataforma apresenta indicadores financeiros, gráficos interativos, comparação de cenários, análises de fluxo de caixa e simulações financeiras para apoiar a tomada de decisões.

<br><br>

## Componentes do Sistema

- **Módulo Web (Frontend):** Interface desenvolvida em Python e Streamlit, responsável pela apresentação dos indicadores financeiros, gráficos, filtros e funcionalidades interativas do dashboard.

- **Backend (Processamento de Dados):** Responsável pelo tratamento das bases, cálculos financeiros, indicadores contábeis, análises estatísticas e validação dos dados, utilizando Python, Pandas e NumPy.

O DashBird tem como objetivo central facilitar a visualização e interpretação de informações financeiras, permitindo o acompanhamento de resultados e a comparação entre diferentes cenários simulados.
